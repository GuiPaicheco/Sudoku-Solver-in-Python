# Sudoku Solver em Python

Resolvedor de Sudoku com algoritmo de backtracking e interface gráfica Tkinter.

**Contexto:** Estudo de algoritmos.  
**Tecnologias:** Python e Tkinter.

## Visão do projeto

O solver percorre as células vazias e testa candidatos de 1 a 9, verificando linhas, colunas e blocos 3×3. A interface usa Tkinter. A validação inicial de tabuleiros contraditórios ou fora do intervalo ainda merece atenção.

## Executar localmente

Requer Python 3 com Tkinter disponível.

```bash
git clone https://github.com/GuiPaicheco/Sudoku-Solver-in-Python.git
cd Sudoku-Solver-in-Python
python SudokuSolver.py
```

O programa executa os exemplos contidos no arquivo e abre uma janela gráfica.
